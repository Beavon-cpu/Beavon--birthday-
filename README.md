# Happy Birthday, Beavon Ouko! 🎂

A simple birthday surprise website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` – the page
- `style.css` – colors, layout and animations
- `script.js` – surprise button and confetti
- `cake.svg` – the birthday cake picture

## View it locally

Open `index.html` in any browser, or run it from IntelliJ using the browser icon at the top right of the editor.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example `beavon-birthday`).
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then click **Save**.
5. After a minute, your site will be live at `https://YOUR-USERNAME.github.io/beavon-birthday/`.
